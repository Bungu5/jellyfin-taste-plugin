Rating dialog

Intro Skipper or Chapter Segments Provider gives exact credits. Without them, stopping in the last part of the runtime counts as the credits.

Recommendations

Adds "Movies for you", "Shows for you", and the rows of titles to request to the Jellyfin Web home screen, after Continue Watching and Next Up. Empty rows are left out. Each person can reorder or hide them under Taste → Sections. When this is off, the rows show on the Taste page instead.
Leave empty to use Seerr instead: Seerr already talks to TMDB, so setting the Seerr URL and API key below is enough. Responses are cached.
Adds "New movies / New shows to request" (released in the last five months) and "More movies / More shows to request" (older) with titles you do not have yet. Needs Seerr or a TMDB key. Nothing is requested or downloaded automatically.

Better picks (optional, free)

From trakt.tv/oauth/applications → New application (any https redirect URI, e.g. https://example.com/; Taste never signs in to Trakt). Adds "fans of this also liked" lists and trending new shows. Only the client ID is needed.
From mdblist.com → Preferences → API key (free: 1,000 calls a day; Taste uses a few dozen). Adds IMDb, Rotten Tomatoes, Metacritic, and Trakt scores so weak titles are left out.

Seerr

Jellyseerr or Overseerr, as Jellyfin can reach it. Turns on the rows of titles to request, the Request button, and calibration posters.
From Seerr Settings → General. Requests are made as the signed-in person, so their Seerr quotas and approval rules still apply. Titles already available or requested in Seerr are marked or left out.
